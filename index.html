3. Loops: When We Want To Do Something Over and Over Again

In general, loops tell your program to repeat a task and are a staple in all programming languages. Loops do something as many times as you tell it to.. which is pretty awesome. What’s not awesome about loops is the syntax.

There are 3 types of loops: for, while, and repeat. This lesson covers for loops.

For Loops

A for loop allows you to repeat an action for every item in a list or vector.

General Syntax

for (value in sequence)

{ # execute this code }

Simple For Loop Example

Let’s say we have an object that has all the days of the week stored in called week.

week <- c('Sunday',
          'Monday',
          'Tuesday',
          'Wednesday',
          'Thursday',
          'Friday',
          'Saturday')

I could write a for loop to print all the days of week from that vector

for (day in week) {
  print(day)
}
[1] "Sunday"
[1] "Monday"
[1] "Tuesday"
[1] "Wednesday"
[1] "Thursday"
[1] "Friday"
[1] "Saturday"

Here, I’m telling R for the entire vector “week”, print the day of the week for each pass.

  • Pass 1: R sets day = Sunday, so it prints “Sunday”

  • Pass 2: R sets day = Monday, so it prints “Monday

  • …and so on, until it finishes all 7 days!

Note that the variable name day is arbitrary - you could call it for (i in week) or for (x in week). Naming it day simply makes the code readable and self-documenting.

You could also use a for loop to do something across all the rows in your data frame.

Applied For Loop Example: Calculating Individual Score Improvement

Goal: To calculate the change between baseline and follow-up scores for each participant (followup_score - baseline_score) and add it to our data frame.

First, we need to create a vector to store the results in. We want this vector to have as many slots as our rehab_data data frame. We’ll call this vector we’re creating score_change.

score_change <- numeric(nrow(rehab_data))

Look in Environment. What do you see?

Then, we will write our for-loop to calculate this change score.

We want our for loop to

  • Iterate row-by-row of our data frame, rehab_data. (what we specify immediately after for)

  • To perform followup_score - baseline_score for (what will go in curly brackets)

  • To perform the operation for each participant

  • And to store each calculation into the empty vector we created called score_change, which means we want everything assigned here (<-)

for (i in 1:nrow(rehab_data)) {
  score_change[i] <- rehab_data$followup_score[i] - rehab_data$baseline_score[i]
}

Look in Environment. What changed in the score_change vector?

Now, add score_change to your data frame by assigning it to a new variable within rehab_data.

rehab_data$score_change <- score_change

4. Conditionals: Introducing Logic Into Your Code

Conditionals are a way to introduce logic into your code, with the most common conditional statement sbeing “if” and “if-else”.

If Statement

Think of an if statement like a fork in the road. It asks R a simple true/false question. If the answer is TRUE, R follows the path inside the curly braces { }. If it’s FALSE, R ignores that path entirely and moves on.

Let’s say we wanted to look at P001’s visits and see if they were greater than the visit minimum of 5.

p001_visits <- rehab_data$visits[1] 
if (p001_visits >= 5) {
  print("This participant has met the minimum requirement!")
}

Since their visit number is NOT greater than 5, nothing happened. If we wanted something to print to tell us that, we would use an “If-Else” statement.

If-Else Statement - Option 1

if (p001_visits >= 5) {
  print("This participant has met the minimum requirement!")
} else {
  print("This participant has NOT met the minimum requirement!")
}
[1] "This participant has NOT met the minimum requirement!"

Here, we’ve added an else argument that specifies what to do if the previous condition is not met.

If-Else Statement - Option 2 (Vectorized Format)

General Syntax - Vectorized Format

  • ifelse(conditional statement, “Printed If True”, “Printed If False”)

Here’s the same example written differently.

ifelse(p001_visits >= 5, "This participant has met the minimum requirement!","This participant has NOT met the minimum requirement!" )
[1] "This participant has NOT met the minimum requirement!"

You could also use an if-else statement to categorize participants based on a condition or threshold.
